## Direction contract

THESIS: The page opens as a harbor operations board — one unmistakable go/no-go
condition signal first, then the technical evidence that backs it — refusing
the category default of a hero banner followed by identical stacked panels.

OWN-WORLD: Identity is fixed, not invented: navy/cyan (`--bg` #0a1a28,
`--accent` #5bd0f0), Fraunces for display numerals, Inter for body, tabular
nums throughout. New structural vocabulary: a full-width status strip whose
background color is driven by the live Escala de Ondas class (Muito
baixa→Extrema), replacing the generic hero as the true top of page; below it,
a true CSS grid (not a flex stack) of panels sized and ordered by urgency —
alerts/escala get visual weight, technical series (wave/energy/wind/temp/tide)
form a denser secondary grid. Severity is expressed as threshold/condition
bars translated into navy/cyan plus one reserved alert hue, never neon.

STORY: A visitor reads the condition class and color in under two seconds
(go/no-go). A technical user scans past the strip into a real multi-column
data grid instead of scrolling a single stacked column.

FIRST VIEWPORT: Full-width condition strip (place name, live escala class,
class color fill, key numbers: Hs/Tp/wind/maré) spans the top, replacing
`header.hero`. Immediately below, a two-track grid begins: left track
(narrower) carries alerts signup + escala explainer; right track (wider)
carries the summary/week panel. Everything below continues in a structured
grid, not a single flex column.

FORM: My own grounded candidate (harbor operations board / go/no-go status
board), dealt index 1 from the ranked structural list for `impeccable
concept-seed --scope surface --mode operate`, seed key 84375f28; raised with
a translated severity/threshold-banding grammar donated by the competitive
challenger `pop-culture-shelf-anime-command-center` (kept: condition bars
filling by severity, banded warning framing — never its literal neon
palette).

FINISH: unreviewed and undocumented is unfinished; this build ends with the
finish review, the verdict, DESIGN.md, and every shipping raster carrying its
provenance.
